# Risk Register

Pilot-specific risks, mitigations, and current status. Severity: L/M/H.

| #   | Risk                                                        | Likelihood | Impact | Mitigation                                                                                                                                                                             | Status                                                               |
| --- | ----------------------------------------------------------- | ---------- | ------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------- |
| R01 | **Demo e-wallet mistaken for real payment**                 | M          | H      | Prominent bilingual "DEMO ONLY — NOT A REAL PAYMENT" warnings on every demo screen, receipt, and admin badge; `DEMO-` reference format; demo totals labeled simulated in the dashboard | Mitigated; reinforce during staff training and UAT                   |
| R02 | **Add-on compatibility matrix is provisional**              | M          | M      | Documented in MENU_VALIDATION.md with a client sign-off checklist; matrix centralized in one seed rule set; changing it is a seed-only change                                          | Open — requires client confirmation before finalizing the pilot menu |
| R03 | **Menu/price changes require a developer**                  | H          | L      | Admin cannot edit prices by design (spec scope); seed is idempotent so operator can re-seed after code changes; documented in KNOWN_LIMITATIONS                                        | Accepted for pilot                                                   |
| R04 | **Tablet lost/stolen with PWA installed**                   | L          | M      | No personal data on device; no credentials in browser storage; admin console requires login; certificates are private-CA only                                                          | Mitigated                                                            |
| R05 | **Kiosk left unattended → abandoned carts/timeouts**        | M          | L      | 105 s warning + 15 s grace + 120 s reset; auto-reset after confirmation; supervised pilot                                                                                              | Mitigated                                                            |
| R06 | **Duplicate orders from double-tap/retry**                  | L          | H      | Idempotency-Key with sessionStorage reuse; server unique constraint; verified by E2E + integration tests                                                                               | Mitigated (tested)                                                   |
| R07 | **Server crash mid-order**                                  | L          | M      | Immediate transactions; WAL; order either fully committed or not at all; client retries with the same key and gets the original order                                                  | Mitigated (tested)                                                   |
| R08 | **Database corruption**                                     | L          | H      | WAL + synchronous=NORMAL; `PRAGMA integrity_check` in healthcheck, backup, and restore; backups verified; quarantine-on-restore                                                        | Mitigated (tested)                                                   |
| R09 | **Accidental database reset**                               | L          | H      | `db:reset` requires `--confirm-reset`, quarantines instead of deleting; restore quarantines too                                                                                        | Mitigated (tested)                                                   |
| R10 | **Restore while server is running → corruption**            | M          | H      | Lock file guard refuses restore; stale-lock removal documented                                                                                                                         | Mitigated (tested)                                                   |
| R11 | **Offline kiosk queues orders silently**                    | L          | H      | Offline state disables checkout entirely; cart preserved; never queues                                                                                                                 | Mitigated (tested)                                                   |
| R12 | **Admin session hijack on LAN**                             | L          | M      | httpOnly + SameSite=Strict + Secure cookies; CSRF on mutations; no-store; rate limiting; short inactivity timeout                                                                      | Mitigated                                                            |
| R13 | **Untrusted CA / HTTPS misconfiguration**                   | L          | H      | Production startup refuses inconsistent security config; internal-CA trust documented per device; remove-cert instructions after pilot                                                 | Mitigated; verify per device during deployment                       |
| R14 | **Public exposure of the shop PC**                          | L          | H      | Caddy binds LAN; firewall rules LAN-only; no port forwarding; Node bound to 127.0.0.1                                                                                                  | Mitigated; verify firewall during deployment                         |
| R15 | **Receipt token leaked**                                    | L          | M      | Token returned once; only SHA-256 stored; wrong tokens indistinguishable from missing; receipts never cached                                                                           | Mitigated                                                            |
| R16 | **Test evidence not reproducible by school**                | M          | M      | All test commands are documented and rerunnable (TEST_RESULTS.md lists exact commands); lockfile committed; fresh install verified                                                     | Mitigated                                                            |
| R17 | **Physical-device issues (pinning, orientation, printing)** | M          | M      | DEPLOYMENT.md covers Android/iPadOS steps; printing uses the browser print dialog; no printer driver support by design                                                                 | Open — requires on-device UAT (not performed on hardware)            |
| R18 | **Business date confusion near midnight**                   | L          | L      | All dates derived from Asia/Manila at order time; verified by unit tests                                                                                                               | Mitigated                                                            |
| R19 | **Rate limiting blocks legitimate staff**                   | L          | M      | 300 req/min per IP; login limiter is per IP+username with reset-on-success; documented                                                                                                 | Mitigated                                                            |
| R20 | **Scope creep into excluded features**                      | M          | M      | Excluded features explicitly listed in SRS/KNOWN_LIMITATIONS; no inventory, discounts, accounts, delivery, etc.                                                                        | Controlled                                                           |

## Residual risks requiring client/school decision

- **R02** add-on matrix confirmation.
- **R17** physical-device behavior (pinning, guided access, print).
- Replacement of placeholder brand assets with production assets
  (visual only — no logic changes required).
